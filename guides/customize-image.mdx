---
title: Customize the worker image
description: Add packages, source code, and environment variables to new sessions.
icon: layer-group
---

Customize the image block in the generated application. Add every build operation
before `prepare_image()`:

```python
base_image = (
    worker.base_image()
    # Add custom build operations here.
)
image = worker.prepare_image(base_image)
```

## Install packages

Use the normal [`modal.Image` API](https://modal.com/docs/guide/images):

```python
base_image = (
    worker.base_image()
    .apt_install("ripgrep", "jq", "postgresql-client")
    .pip_install("pytest", "ruff", "httpx")
)
image = worker.prepare_image(base_image)
```

## Set environment variables

```python
base_image = (
    worker.base_image()
    .env(
        {
            "PYTHONUNBUFFERED": "1",
            "PROJECT_ROOT": "/root/workspace/app",
        }
    )
)
image = worker.prepare_image(base_image)
```

Keep credentials out of image environment variables. Attach a
[Modal Secret](https://modal.com/docs/guide/secrets) to the operation or function that
needs it.

## Add project source

For a public repository:

```python
base_image = worker.base_image().run_commands(
    "git clone https://github.com/acme/widgets /root/workspace/widgets"
)
image = worker.prepare_image(base_image)
```

For local source, use Modal's source-mount or copy operations before `prepare_image()`.

## Disable optional tools

```python
base_image = worker.base_image(
    python_version="3.12",
    install_ffmpeg=False,
    install_chrome=False,
)
image = worker.prepare_image(base_image)
```

| Option | Default | Effect |
| --- | --- | --- |
| `python_version` | `"3.12"` | Selects the Python version |
| `install_ffmpeg` | `True` | Enables screen-recording support |
| `install_chrome` | `True` | Enables browser and computer-use support |

For the complete list of what the standard image includes, see the
[image reference](/reference/images).

<Warning>
  Keep `prepare_image()` last. A resumed session uses its preserved filesystem;
  redeploying a new base image leaves an existing suspended workspace unchanged.
</Warning>
