This tutorial verifies the outpost and Modal application created by the interactive
setup wizard.

## Before you begin

Complete [Create an outpost interactively](/tutorials/create-an-outpost), including
accepting **Deploy now?** at the final prompt.

## Start a session

Create or resume a Devin session and select the outpost you deployed. Then
open the Modal application logs.

The first session can take longer while Modal builds the required images. Later
starts reuse those build results when possible.

<Check>
  The deployment is working when a session invocation starts and its logs show the
  Devin worker processing your session.
</Check>

If no invocation starts, follow [Troubleshoot a deployment](/guides/troubleshooting#no-session-starts).
