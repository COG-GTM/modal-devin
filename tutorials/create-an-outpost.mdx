title: Create an outpost interactively
description: Create a Devin Outposts outpost and deploy its Modal orchestrator.

---

Use the setup wizard when you need a new outpost. It can configure
Modal, create the outpost, store the Devin token, generate the application, and
deploy it.

## Before you begin

Install the package:

```bash
uv add modal-devin
```

You also need a Devin organization with Outposts enabled and a token authorized to
create and serve outposts. This wizard runs without a local Devin CLI because `init`
creates the outpost through the Devin Outposts API.

<Steps>
  <Step title="Start the wizard">
    ```bash
    uv run modal-devin init
    ```
  </Step>

  <Step title="Configure Modal if prompted">
    When local credentials are missing, accept **Set up Modal now?** to launch
    `modal setup`.
  </Step>

  <Step title="Name the deployment">
    Choose a durable name that describes the outpost's role, such as
    `frontend-production` or `gpu-builds`. The wizard uses it for the outpost,
    generated filename, and Modal resources.
  </Step>

  <Step title="Provide the Devin token">
    The wizard uses the token to create the outpost and offers to store it as a
    Modal Secret. Input is hidden, and the generated application excludes the token.
  </Step>

  <Step title="Deploy">
    Accept **Deploy now?** or deploy the generated file later:

    ```bash
    uv run modal-devin deploy outposts/<generated_name>.py
    ```
  </Step>
</Steps>

## If setup fails

The wizard avoids overwriting existing files and reports any remote resource that
may need cleanup. Follow the printed recovery step, then rerun the command after the
underlying problem is fixed.

## Automate setup

For non-interactive use, provide a name and an existing outpost ID:

```bash
uv run modal-devin init ci-outpost \
  --outpost-id outpost_env-... \
  --secret-name ci-devin-token \
  --outposts-dir deployments \
  --no-deploy
```

When `--outpost-id` is omitted, `init` creates a new outpost by calling the Devin
Outposts API directly. In a non-interactive environment, make sure
`DEVIN_OUTPOSTS_TOKEN` is set so the request can be authorized.

See the complete [`init` option reference](/reference/cli#modal-devin-init).
